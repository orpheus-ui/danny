# Plans

One file per piece of planned work bigger than a PR — a milestone, or a feature
spanning several PRs. Named `YYYY-MM-DD-<slug>.md` by the date it was written.
[roadmap.md](../roadmap.md) says *what* and *in which order*; a plan says *how*.

Every plan starts with a status table, kept true after each merge:

```markdown
# M1 — Match the design

| Task | Status | PR |
|---|---|---|
| tokens — Figma colors and type into `D` | merged | orpheus-ui/danny#4 |
| progress-bar — Metal shader, two-tone label | in review | orpheus-ui/danny#5 |
| card — full-bleed thumbnail and scrim | not started | — |
```
